# Sticker

A small tilted badge with a chunky `on-bright` outline and drop edge, like a sticker slapped on a flyer. It holds one to three words of status or hype.

- `tone` sets the fill (zap by default). `tilt` sets rotation in degrees (−4 by default). Alternate tilt direction when stickers sit next to each other.
- Copy is uppercase display type. Keep it short: "New", "Hosting", "2 spots left".
- Use one or two per card at most. Stickers are seasoning.
