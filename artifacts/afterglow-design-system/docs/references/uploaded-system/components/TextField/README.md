# TextField

A glass input or textarea with a label above it and a hint or error below. On focus, the border turns pop pink with a soft aura ring.

- Use `multiline` for a textarea (3 rows, resizes vertically).
- `error` replaces the hint and turns the border and hint `danger`. Write errors like a friend would: "That number looks short."
- All native input props pass through (`value`, `onChange`, `type`, `placeholder`).
- Placeholders show an example, not an instruction: "Rooftop szn", not "Enter event name".
