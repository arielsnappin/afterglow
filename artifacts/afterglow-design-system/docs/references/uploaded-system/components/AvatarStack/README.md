# AvatarStack

Overlapping round avatars that show initials on neon fills, with a glass "+N" overflow chip and an optional caption.

- Tones cycle through pop, zap, sun, sky and grape. Set `tone` on a person to keep their color stable everywhere.
- `max` is the number of avatars shown before "+N" (4 by default). `total` gives the real count when `people` is only a sample.
- Sizes: `md` (40px) and `sm` (30px, used inside cards).
- Make captions social and specific: "Mika, Jo & Sam are in" beats "3 attendees".
- **The page provides:** photo avatars later, if needed. Keep the 2px `bg` ring so overlaps stay crisp.
