03Builder notes

Decisions taped to the wall.

  • Trust

    Three states, never merged

    Data model keeps registration, check-in and meeting apart. No inferred meetings.

  • Safety

    Synthetic by design

    Simulated Luma or one bundled CSV. Same fictional scenario, stable IDs. No open uploads.

  • Voice

    Templates, not AI

    Drafts come from your notes and shared events. You edit. Nothing sends.

06Proposed metricsNot collected

Three signals. Zero data yet.

  1. i.

    First useful follow-up

    A follow-up the user reviewed and saved.

  2. ii.

    Replies within 7 days

    Only replies the user confirms. Never draft counts.

  3. iii.

    Back for the next event

    The user returns when the next guest list lands.

Pilot first to learn baselines. No targets claimed.
